# MIT 全图演示改造计划

目标：在现有 840 × 840 米本地场景内，一次交付连续、可浏览、可步行的环境基础层。保留测绘建筑与地形，不把基础材质覆盖描述为精细复原。

## 实施清单与验收

1. **全图数据底层**：核对现有建筑、地形、航拍及 GIS groundplan。新增地表优先依据已下载的地理配准数据；缺失部分记录近似范围。验收：原始坐标、建筑数量与原始对比模式保持可用。
2. **建筑统一处理**：核心七个模型保留既有细节；全图墙面与平屋顶分离，外围增加克制的材质差异。验收：不覆盖核心柱廊开口，不新增悬空或错误碰撞。
3. **地表与植被**：扩展核心区外的绿地、步道、河岸环境；树木避开建筑与硬质通路。验收：可视化检查边界，步行检查核心连通路线。
4. **画面统一**：增加自然天空和远景过渡，统一材质与光照。验收：远景仍可辨认，核心近景保持清晰。
5. **浏览与性能**：增加全图及河岸观察机位；复用贴图、合并几何，不按树木数量增加独立绘制调用。验收：加载与模式切换无脚本错误，记录模型大小和场景开销。
6. **最终回归**：构建、单元测试、固定机位、原始/增强切换、两校故事以及两侧庭院真实键盘漫游。更新制作清单和限制后统一交付。

## 本批不包含

- 225 个模型的逐栋实拍精确复原、真实室内、完整道路交通系统。
- 将普通建筑一律套用同一种精细窗格，或为未知建筑编造具体用途。
- 实时外部地图依赖。已有照片中的阴影、年份差异及局部配准误差需保留说明。

## 交付验收与剩余边界

- 构建、24 项单元测试、原始/增强切换和固定机位检查通过；完整键盘漫游覆盖主楼台阶、中央区域和两侧庭院。两校原有加载、交互、照片、航拍与无 WebGL 降级也经过回归。
- 重建流水线：先运行 `prepare-mit-environment.py`，再运行 `build-killian-detail.mjs`。核心立面另由 `prepare-killian-detail.py` 生成。
- 图面颜色是道路和绿地的候选分类，部分真实草坪仍显示为通用地块，未强行涂满；道路标线、路缘和复杂路口没有完整三维重建。边缘平滑与水域碰撞分类可能相差约一个单元。
- 水面无动态流体；图像缺失区及范围边缘的桥段仍简化。低位航拍补面改善视觉孔洞，不代表桥面/桥墩已完整建模。
- 树种、精确树位、建筑专属材质、立面窗数、室内仍未实测复原。更细的真实效果需要逐栋参考照片与更明确的景观矢量数据。
- 未新增外部实时请求；未调用 Tripo、未导出 Google Maps 网格、未发布网站。

### 最终验收

- `npm run build` 通过。
- 27 项单元测试通过，覆盖桥体几何分离、不重复/丢失三角形、核心建筑不套用通用立面、水域/桥面判断及资产完整性。
- `check-killian-sample.mjs` 通过，检查所有固定机位、原始/增强切换、标准/省电切换，并捕捉脚本及着色器控制台错误。
- `check-local-campus.mjs` 通过，覆盖 MIT/Harvard 加载、交互、照片、航拍与无 WebGL 降级，确认没有外部地图请求。
- 主楼台阶及两个侧庭院已用真实键盘移动通过回归；`check-campus-story.mjs --bridge-only` 最终通过，从校园沿桥头到桥面远端观察位置，检查角色高度落在桥面上。
- 桥面近景检查快照约 16 次绘制、577824 个三角形；统计随视角、阴影和可见物体变化，不构成各设备帧率承诺。

### 数据边界

场景范围仍为 840 × 840 米，桥梁只延伸到本地范围边缘。特殊建筑专属立面、真实室内、真实桥梁结构尺寸及完整交通系统不在本次演示版完成范围内。通用立面、道路标线、桥栏杆/支撑及连接面均为视觉近似，不能用于现实导航或工程用途。
