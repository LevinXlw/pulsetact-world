## 本轮改动

- 以独立的照片研究配置和建模模块制作 10 号楼柱廊。由开口边界划分墙体，替换此前覆盖整个后立面的实心薄墙；窗洞有侧壁，玻璃后退约 0.35 米。
- 依据已有官方正面照片的开口关系，制作五个中央高窗和两侧分层窗，三组门分别增加门框、双扇、下部面板和把手。玻璃反射与透明度结合浅层遮挡，未建造真实室内。
- 柱脚增加底座和分层线脚，柱身保留凹槽与收分；柱头使用卷涡曲线，补连续檐底与檐口分层。铭文字形继续使用已有字体，近景仍是近似。
- 台阶增加分块边缘；保持原有五级台阶及平台高度。柱廊地板、台阶、墙面和柱身采用区分用途的石材处理，补轻微块间差异和有限的檐下、墙根变化。
- 调整主庭院草坪的颜色与较大范围变化，天空增加轻薄云层。树木几何、81 个树位和背景建筑制作范围未扩展。
- 新增「主楼门窗」「柱廊侧视」观察机位，均在当地面以上约 1.65 米。门窗近景允许较短镜头距离，防止轨道控制器把机位推离设定位置。

制作配置：`assets-source/killian-reference/portico-study.json`。

模型生成：`scripts/portico-geometry.mjs`，由 `scripts/build-killian-detail.mjs` 调用。

材质处理：`src/features/real-campus/portico-finish.ts`。

## 实际验证

- `npm test`：9 个测试文件，34 项测试通过。
- `npm run build`：TypeScript 和生产构建通过。仍有 Three.js 公共块体积提示。
- 新增几何验证：逐个窗洞和门洞没有残留实心墙；邻接墙面仍实体闭合；玻璃在墙面之后且有独立背景层；五级台阶与平台高度不变。
- `node scripts/check-portico-sample.mjs`：四组观察机位、镜头高度、浏览器错误检查和真实键盘路线通过。角色从草坪上台阶、到平台和门前、横向经过柱间，再下台阶返回。
- 录屏通过浏览器的 Canvas Capture / MediaRecorder 保存为 `screenshots/portico-v2/after/portico-walk.webm`；实际播放已验证，不依赖 FFmpeg。画面来自运行中的场景，没有通过脚本修改角色位置。
- `node scripts/check-local-campus.mjs`：MIT / Harvard 加载、互动、移动暂停、照片、航拍和无 WebGL 降级通过。
- `node scripts/check-realism-delivery.mjs`：主体优先可交互、gzip 请求、无外部运行资产、加载后断网切换机位、树冠失败恢复通过。
- 对照页验证：四组图片、比较滑块、录屏播放和 390px 窄屏布局通过。

本机 Headless Chrome、1440×900 窗口、柱廊侧向机位、5 秒采样，前后帧间隔中位均约 4.2 ms，p95 均约 4.3 ms。这是自动化环境的短采样，不能作为用户设备持续帧率或 1080p 十分钟性能验收的证明。[完整本轮报告](screenshots/portico-v2/after/report.json)

本轮使用已可重复运行的独立浏览器脚本；原有 `npm run test:e2e` 启动停滞问题没有在本轮解决，也没有记为通过。

## 真实程度与后续

结构参考来自 MIT List 官方照片，沿用 GIS 锚点。门窗深度、石块尺寸、细部构造和表面痕迹仍包含推定；未完成现场测量。浅层窗后遮挡只服务外观，不代表实际室内布局。

后续顺序：补齐 3/4 号楼可见立面参考并分楼制作；完成一棵树的近景样板；完善庭院地面边界与树荫；再扩展连续河岸路线和环境漫步。当前交付是主楼柱廊样板，不是整份现实场景方案完成。
