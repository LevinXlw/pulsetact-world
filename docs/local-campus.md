# 本地实景校园

入口：`/real/mit`、`/real/harvard`。运行 `npm run dev` 后即可使用，不需要配置 Key。模型和影像全部由本机开发服务器提供；没有使用 Google 图像或抓取 Google Tiles。

## 数据与转换

原始 ZIP 位于 `assets-source/cambridge-gis/`；原始文件校验、下载来源与使用说明保留在该目录。`scripts/prepare-campus-data.py` 从 ZIP 直接读取，不联网，依赖 Python、numpy、Pillow。运行后输出 `public/data/campuses/{mit,harvard}/campus.glb`、`overview.jpg` 和 `manifest.json`。

- MIT：225 栋建筑，30,085 个建筑三角形，38,634 个地形三角形，GLB 11,581,344 bytes。
- Harvard：652 栋建筑，87,969 个建筑三角形，79,753 个地形三角形，GLB 20,221,544 bytes。
- 每校范围 840 × 840 米；建筑按中心点选入，边缘有裁切。不是整座城市。
- EPSG:2249 / GRS80 Lambert 投影；扣除来源坐标偏移后，将 US survey feet 转为米，场景使用东 / 上 / 南三个轴。
- 使用世界文件对齐航拍图；4096px 图像嵌入 GLB，1600px 总览用于二维地图。
- 建筑 2023、地形 2018、影像 2025。地面与建筑年代不同，局部高度、阶梯和轮廓可能不一致。
- 保留真实建筑几何，但外墙无照片纹理。树冠来自地面航拍，不是立体树木。地标标记放在室外观察点，不表示可进入建筑。

## 操作与状态

鸟瞰：拖动旋转、右键平移、滚轮缩放。漫游：WASD / 方向键，Shift 奔跑，E 与附近人物交谈或打开地点。角色通过地形射线贴地，通过前方建筑射线阻挡移动；加入镜头缓动、转身缓动、奔跑加速与视野变化、镜头遇到建筑和地形时缩近。不包含完整物理系统、自动寻路、立体楼梯或攀爬。关闭页面或切回航拍后，角色回到入口；真实坐标不会写入艺术化场景存档。

走近 12 米并打开地点会记录探索，鸟瞰和航拍仅预览。收藏、活动和照片复用已有本机存档与手册。真实场景中加入 Alex、Sam、Maya、Leo 四位虚构学生，5 米内可通过分支对话交流；室内仍在艺术化校园入口中。每校新增三步校园故事：先交谈、观察地标、再与另一位学生交流。故事通过已有进度推导，刷新后保留，与艺术化校园共享记录。漫游模式收起侧栏，任务卡显示当前目标、距离和完成状态；打开任务与地点面板会暂停角色。

## 验证

`npm test` 验证 GLB 文件结构、有限坐标、三角形数、关键地标保留、出生点和地点地形覆盖，以及已有逻辑。`node scripts/check-local-campus.mjs` 使用本机 Chrome 检查两校加载、键盘移动、暂停、地点介绍、拍照、航拍、无 WebGL 降级及无外部地图请求，截图输出至 `docs/screenshots/`。可通过 `CAMPUS_BROWSER` 指定其他已安装的 Playwright channel。

本机 Edge 自动化启动失败，Chrome 自动化可用。尚未完成全区域步行巡检、完整相机边角碰撞巡检、移动端漫游和长时间性能测试。原有完整艺术化流程的端到端验收状态不因此改变。
