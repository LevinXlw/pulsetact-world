# v0.2.0 — 校园世界与 BU Commonwealth Avenue 细化

发布日期：2026-10-24。目标分支：`develop`。正式站点：<https://world.pulsetact.ai/>。

这是初始 v0.1.0 提交之后的累计版本，收录此前已在本地实现的校园、人物、单人玩法、建模工具及本轮 BU 街景改造。

## 本轮 BU 更新

- 细化 Commonwealth Avenue 的 GSU／Mugar Link、Warren Towers 临街区域与 Marsh 周边；补充入口、铺装、路缘、过街和景观层次。
- 依据照片修正 Link 高窗墙比例，补充框体、结构柱、三组双扇入口及 GSU 建筑名称；7.4 米高度是照片估算，不是实测尺寸。
- 增加 Link 红砖／浅石庭院铺装、低矮座椅、绿化边界、树池和树篦。
- 修正 Warren 北侧草地侵入人行道的问题，补齐连续步行面、透水砖边带及入口过渡。
- 改善雨棚曲面法线和临街玻璃。桌面使用现有天空反射，手机保留轻量渐变；没有声称新增建筑环境反射。
- 更新手机 Boston 场景及 MIT 建筑替换底图，修正高清切换后的铺装、玻璃材质命名和地面高度，保留 Warren 树木／树池。

## 本次一并入库的累计功能

- 单人校园漫游、角色与昵称、本机存档、地图快速前往、校园旅行及地球分布视角。
- Boston 的 MIT、查尔斯河及 BU 区域，以及 UMD College Park、UPenn、University of Arizona（Tucson）。
- BU CDS／Questrom 建筑、CDS 可进入公共室内与门交互；MIT Stata、Baker、Maseeh 等建筑资产和制作来源。
- 绿线、河岸、水面、地形道路、手机资源预算及入场后高清材质切换。
- 固定账号后端登录、Cloudflare Worker／Durable Object 部署、相关自动化检查。
- 项目真实场景还原规范、源数据、模型生成脚本和资源来源记录。

## 发布验证

- 完整单元／集成测试：76 个文件、383 项测试通过。
- 本轮 BU 已完成桌面／手机实机浏览器检查、固定机位对照，以及每档 15,284 个地面／碰撞采样检查。
- Cloudflare 发布构建通过：124 个资源文件，合计 296.05 MiB。构建仍有部分 JS 分块超过 500 kB 的体积提示。
- 上线后用 `scripts/check-release-bu.mjs` 验证实际版本、登录、BU 地图旅行、手机高清、WebGL 和资源哈希。运行结果保存于本机 `output/deployment/`，不将未运行的线上检查预先记为通过。
- 浏览器手机模拟不等于 iPhone 真机验证。

## 范围与后续差距

本版本是阶段更新，不代表完整校园已达到最终真实感标准。GSU／Mugar 的全部立面、Warren 上部塔楼等仍有较粗旧模型；植物、玻璃及远近材质仍需继续按实景迭代。新近景构件存在照片估算尺寸，本轮没有扩展 GSU／Mugar 室内。

## 复现与凭据

运行资产位于 `public/`，制作输入与脚本位于 `assets-source/`、`scripts/`。临时截图、检查报告、工具缓存和 Blender 自动备份不进入 Git。MIT 宿舍源数据索引固定保存于 `assets-source/mit-residences/source-index.json`。

首次克隆需按 README 从 `server/auth-credentials.example.mjs` 创建被 Git 忽略的实际凭据文件。发布机器保留现有密码；该密码只供后端构建使用，不写入提交或浏览器资源。
