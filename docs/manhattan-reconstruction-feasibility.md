## 关键判断

已经具备建筑模型、贴图和世界分块资源的读取基础，有继续恢复游戏城市的技术路径。但当前尚未建立“资源引用 → 实例变换 → 区块坐标 → 世界坐标”的可靠映射。

上游 [ALERT 的 Zone 格式说明](https://github.com/Tkachov/ALERT/wiki/.zone)明确表示场景格式研究不完整；本地解析器中的多个数据段也只有原始整数或字节解析。例如 `06ABCAB2` 仅被注释为可能的矩阵数据。不能把找到这个段当作已经恢复摆放矩阵。

读取模型、枚举场景资源与完整恢复场景是不同的完成标准。目前帝国大厦页的主体经过手动及程序化重建，周边楼群是程序生成的氛围示意；它们不是自动导出的曼哈顿世界。

## 实施顺序与验收

1. **恢复一个游戏原始区块。** 解析静态实例的模型引用、位置、旋转、缩放及父子变换；验证街道连续、建筑方向正确、比例一致，且可以从同一源文件确定性重建。此阶段以完整区块坐标链路为验收，不再手工猜测楼群位置。
2. **拼接连续区块。** 验证相邻区块无重叠或缝隙，区分基础场景与任务、时间、剧情覆盖层，处理重复实例、嵌入几何和材质覆盖。地理位置明确后选择帝国大厦及周边作为精细展示区。
3. **扩大到整岛。** 建立区块清单、按相机距离加载、远景简模、共享材质、实例复用和纹理压缩。逐区记录未支持资源，避免用随机楼群掩盖缺失块。
4. **恢复观感。** 单独处理游戏专有材质、室内窗景、贴花、植被、天空、灯光与水面；它们不会随几何导出自动达到原游戏效果。

首个区块验证成功前，不承诺整岛的还原比例、完成时间、总下载体积或帧率。浏览器 Demo 的工作方案是分块加载；整岛单个巨大 GLB 不适合作为默认交付方式。

## 重现

沿用现有项目内 ALERT、Python 依赖和名称表：

```powershell
python scripts/inspect-spiderman-world.py "C:\Program Files (x86)\Steam\steamapps\common\Marvel's Spider-Man Remastered"
```

脚本仅输出项目内审计文件，明确标记 `sceneTransformsRecovered: false`。它不覆盖已有预览，不批量解包整个安装目录，也不写入游戏文件。
