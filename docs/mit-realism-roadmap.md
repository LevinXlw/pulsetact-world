# MIT 写实化改造计划

> 2026-09-15：后续制作请参照 [现实场景设计方案 v2](mit-realism-design-v2.md)。本文保留原方案和第一轮实施历史。

2026-09-13。本文是下一阶段方案，尚未实施。目标是提高人在校园地面视角下的可信度，保持本地资产运行。

## 现状判断

当前 225 个 GIS 模型中 10 个部分细化、215 个基础材质模型；2380 组窗格主要为程序重复生成，不能作为真实立面依据。增强资产约 63.3 MB。已具备地形、航拍、道路、水域、81 棵树与校园到桥面连通路线。

主要缺口按影响排序：

1. 建筑身份不足：相同窗格、同色墙面、平整玻璃让不同建筑看起来像同一套积木。现有墙面使用通用混凝土扫描材质代替石材，并用颜色倍率补亮，需重新校准。
2. 地面视角不成立：航拍里有树冠、车辆和建筑阴影，投到地面后成为扁平图案；屋顶影像有拉伸、年份和配准差异。
3. 接触与受光不足：当前固定 2048 阴影贴图覆盖约 280 米宽区域，近景小构件精度有限；缺少稳定的墙角、窗洞、柱脚遮蔽层次。
4. 景观缺少结构与尺度：树冠形状、树位、路缘、铺装收边和小型设施需要依据照片组织。
5. 呈现偏地图工具：鸟瞰机位、常驻手册、卡通人物与浮动标记会削弱写实环境展示。

## 范围与分层

首轮重点路线：Killian Court → 10 号楼柱廊 → 一侧庭院 → Memorial Drive 河岸。先选择容易获得参考且无遮挡的一侧庭院，再锁定路线。

- 近景 0–30 米：真实比例的窗洞/门洞、窗台、材质细节、路缘与地面接缝。
- 中景 30–150 米：准确轮廓、建筑专属立面分区、主要树群与道路边界。
- 远景 150 米外：测绘体量、色彩、屋顶与树冠轮廓。简化细部，通过距离分级保持稳定帧率。

距离为初始制作预算，依据场景实测调整。全图空间关系保留；先达到连续路线的画面质量，再扩展建筑数量。

## 实施顺序与交付

| 阶段 | 具体工作 | 交付与验收 |
|---|---|---|
| 0：参考与基线 | 设置 6 个固定人眼高度机位；逐机位建立照片、拍摄方向、光照和来源记录；记录现有帧率、内存和加载量 | 同机位基线截图、参考板、缺失素材清单。区分测绘、照片确认、推测三种依据 |
| 1：整体画面 | 固定晴天或薄云白天一种光照；校准曝光、石材颜色和粗糙度；提高近景阴影精度，增加接触遮蔽；调整天空、玻璃反射与远景过渡 | 原始/新画面同机位对比；窗框、台阶、墙根阴影可辨；不能靠过曝、浓雾、景深掩盖问题 |
| 2：连续地面 | 对核心路线重建铺装、路缘、台阶边缘、草地交界；航拍仅用于定位及远景底层；分区处理屋顶图像，去除明显错位的视觉图案 | 地面不再出现明显的扁平树冠/车辆；无悬浮、闪烁、穿地和突变高差；保留步行连通 |
| 3：重点建筑 | 优先校准 10 号楼及面对庭院的 3、4 号楼立面；依据照片修改层数、窗距、门窗比例、石材分缝和入口；未确认部分维持简化 | 每栋至少一组同方向参考对照；停止以通用窗格数量作为质量进度；已完成状态按具体可见立面记录 |
| 4：景观与设施 | 根据参考组织乔木、树池、草坪边缘；补少量有依据的长椅、灯杆、垃圾桶、自行车架；变化由结构与使用痕迹产生 | 设施尺度正确、不挡路、不随机堆放；树木有树干、主要分枝与多层树冠；近景与远景使用不同精度 |
| 5：展示与性能 | 增加环境展示模式，收起任务标记和手册；设置约 1.65 米观察高度；模型分区、距离分级、纹理压缩和重复对象实例化 | 一条连续可浏览路线；首屏按需加载；标准/省电都可用；原始对照、既有漫游不回退 |
| 6：交付验收 | 固定机位视觉回归、路线键盘行走、浏览器错误检查、性能采样；整理模型/素材来源和剩余近似部分 | 6 组对照截图、连续路线演示、实测性能记录、逐立面完成清单 |

阶段 1 可以利用现有资产先实施。阶段 2/3 的真实布局与比例应依赖阶段 0 参考，不得用无依据的生成结果冒充校准。阶段 4 可复用前述材质和模块。性能预算从阶段 0 开始跟踪，不留到末尾。

## 素材制作与工具分工

| 来源/工具 | 用途 | 使用边界 |
|---|---|---|
| 现有 Cambridge GIS | 建筑坐标、外轮廓、地形与高度底座 | 保留原始坐标；不同年份数据的差异单独记录 |
| Google Maps / Street View / 三维视图 | 对照建筑外观、屋顶关系、街道设施和观察方向 | 本方案将其作为参考来源；在线 Photorealistic 3D Tiles 是另一条展示路线，不能假设接入后就自动得到永久独立资产 |
| 学校公开照片、摄影资料、现场多角度照片 | 核心立面比例、石材色彩、窗框、入口和景观确认 | 优先同一时期、清晰且少遮挡的照片；透视校正与尺度校准后制作资产 |
| Tripo | 根据单图/多视图生成小型装饰物、雕塑或设施候选模型 | 生成后检查尺度、轮廓、贴图与多余几何；不把 AI 猜出的背面当作实测数据；精确建筑主体沿用测绘与可控模块制作 |
| 扫描材质库 | 石灰石、混凝土、沥青、铺装、树皮的物理材质 | 选择与现场吻合的材质，统一真实尺寸、色彩、粗糙度和纹理密度 |
| 建模/贴图工具与现有 Three.js 项目 | 透视校正、网格修整、窗洞/入口建模、材质烘焙与本地集成 | 先保持现有技术栈；没有证据表明换引擎能解决缺失的真实素材 |

Google 官方说明其 Map Tiles API 提供二维、街景与摄影测量三维瓦片：https://developers.google.com/maps/documentation/tile/overview

Tripo 官方支持多视图输入建模：https://developers.tripo3d.ai/en/docs/generation-multiview-to-model/standard

这些工具能力不等于本项目已调用。当前没有新增 API 接入或采购。

## 首批素材包

- 6 个对照机位：庭院看穹顶、柱廊近景、侧翼立面、侧庭院、道路边缘、河岸。参考缺失时替换机位并记录原因。
- 10/3/4 号楼面向重点路线的每个立面：正面全景、左右斜视、门窗/墙面局部；有遮挡时补充照片。目标是确认可见立面，而非按照片张数凑齐。
- 核心路线铺装、草坪边界、路缘、树种/树形和设施的近景照片。
- 6–8 类匹配现场的基础材质；3–5 类近景树模型和少量街道设施，先做复用资产再布置。
- 清单字段：资产 ID、来源、日期、对应机位/建筑、依据等级、尺寸依据、精度级别、制作状态。

## 验收口径

真实感按轮廓与比例、材质、光影、地面连续性、景观尺度分别检查，不给无测量依据的“相似度百分比”。

画面验收：6 个机位同一视场角和光照条件对比；近景避免窗框悬浮、纹理拉伸、航拍伪物体和重复窗格跨越墙面缺口。核心建筑轮廓及主要开口与参考一致；不能确认的细节明确记录。

性能验收：先在用户实际浏览器/设备记录基线，目标标准模式 1080p 持续不低于 30 FPS，争取接近 60 FPS；这是待验证目标，不是已达成承诺。记录中位帧时间、较慢帧、加载量和显存估算。素材增加必须配合分区、分级和纹理预算。

离线验收：资产预先加载后断开外网，路线浏览不依赖外部地图服务；本地服务仍需运行。

暂不扩展真实室内、完整交通/人群系统、225 个模型的逐栋精确复刻、多天气和昼夜循环。先把单一白天场景与重点路线做可信，再复制到更多区域。

## 2026-09-14：第一轮实施记录

已完成渲染基线、光影与材质基础改造，以及环境展示入口。阶段 0 的同机位实拍参考尚未补齐，不能将六个场景截图称为六组照片校准成果。

- 留存六个固定机位的修改前后截图，新增 `mit-realism-review.html` 本地滑动对照页。
- 标准画质加入 16 采样屏幕空间环境遮蔽，用于近景墙角、窗框和台阶；使用抗锯齿渲染目标及统一色调映射。省电模式释放后处理资源，保持直接渲染。
- MIT 增强模式阴影贴图从 2048 提升至 4096，阴影范围跟随观察中心和观看距离；降低近景法线偏移，改善柱脚和窗框阴影脱离。法线渲染阶段复用主渲染的阴影，避免重复生成。
- 调整天空补光、通用石材颜色与法线强度；玻璃改为更暗的低金属度材质，保留本地环境反射。仍是通用扫描材质，并非 MIT 石材实测数据。
- 已有步道及桥面人行道新增 1.5 米尺度的程序接缝与轻微明度差异，复用原有几何；铺装布局为视觉近似。本轮未重建核心路线以外的航拍地表。
- 新增「环境展示」：拓宽场景、收起手册，隐藏虚构人物与任务标记；点击「返回探索」恢复。保持原有漫游与照片功能。
- 新增 `mit-realism-references.json`：区分已有庭院照片、官方建筑资料和缺失的多角度照片。没有以推测素材冒充真实复原。

验证：构建及 27 项单元测试通过；MIT/Harvard 加载、交互、照片、航拍、无 WebGL 降级通过；固定机位、展示模式和省电关闭/标准恢复环境遮蔽通过。标准模式增加一次法线/深度场景渲染，渲染三角形统计包含多次渲染，不可与之前单次渲染计数直接比较。

性能快照：同一台机器 Headless Chrome、1440×900 窗口、桥面机位、3 秒 requestAnimationFrame 采样，基线中位间隔约 4.2 ms，本轮约 6.1 ms，较慢 95 分位约 11.8 ms。该值仅用于本机自动化相对比较，不是用户屏幕帧率或各类设备性能承诺；完整数据在截图目录 report.json。

下一阶段尚待完成：3/4/10 号楼逐立面照片校准、连续路线地表重建、真实树形/设施素材及分区资产加载。当前建筑制作数量仍为 10 个部分细化、215 个基础模型，增强 GLB 没有增加体积。第一轮着重改善受光和表面层次，不能视为整份写实化计划已完成。

## 树木轮廓与枝叶改造

将原来的大五边形叶片替换为三个渐尖叶片组成的叶簇，加入叶基至叶尖的明度差异；每簇由五个三角形增加到六个。每棵树新增 16 条二级枝条，改善近景枝干结构。叶片颜色采用归一化 8 位存储，减少资产增量。仍为通用阔叶树近似，不代表已识别并复原现场树种。

81 个树位与上一版清单逐项比对完全一致；没有改变道路、水域或行走地表。新增「树木近景」观察机位。增强资产为 74,905,960 字节，较上一版增加约 11 MB；树木仍按材质合并绘制。构建、27 项单元测试、固定机位以及原始/增强、省电切换检查通过。尚未证明在所有设备上达到帧率目标，后续距离分级仍有必要。
