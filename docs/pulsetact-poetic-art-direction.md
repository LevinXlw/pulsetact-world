# Pulsetact World：诗意校园 · 幻想写实

初版日期：2026-10-25；当前修订：2026-10-26。状态：**按用户最新要求明确现实细节优先；MIT 主楼制作与实际运行验收另行记录，本文件不构成完成声明。**

## 1. 当前方向与用户决定

以真实校园的建筑、地形、空间和材质为基础，尽可能还原现实细节。在这些细节成立的前提下，通过自然光照、空气层次与原有色彩的组织，让校园显得宁静、清朗、略带幻想感。

用户希望借鉴所提供 demo 的画风制作 Pulsetact World，并先制作 MIT 主楼；随后明确颜色保持项目之前的风格。2026-10-26 用户进一步明确：**“我还是需要尽可能地还原现实细节。”** 当前方向因此为：**真实的建筑结构与材料细节 + 自然的原有色彩 + 不损失真实性的光影与空气感。**

此前将 demo 理解为允许弱化石材、铺装与玻璃等现实细节的表述不再适用。减少细节不能充当画风，实际材质与可见构件应对照实景继续完善；风格化限于不损失真实性的光影、氛围和色彩组织。建筑比例、构件进深、地形关系、实景依据、可玩性和实际运行验收继续遵守 [项目开发规范](development-standards.md)。历史样板与对照记录保留原始事实，不自动满足此次澄清后的目标。

## 2. 参考的用途

借鉴的视觉语言：

- 建筑轮廓和构件层次清楚，柱础、柱头、凹槽、檐口等有辨识力的细节优先。
- 画面清朗，真实材质与构件层次可读；“干净”不能理解为抹掉石材纹理、磨损、铺装分缝或玻璃深度。
- 亮面、转折面与遮蔽关系明确，远景逐渐融入空气，近景保持可读。
- 环境具有轻柔的动态与留白，水波、树叶和少量粒子为静态建筑提供流动感。

不移植的具体题材：蓝白统一配色、星空夜景、雪白植被、破败断柱、倾斜遗迹和水淹庭院。MIT 仍是一所完整、可漫步的现实校园。

## 3. 保留原有配色

以当前游戏材质和已有 [Cambridge 美术方向](cambridge-art-direction.md) 的自然色彩为基础。下表是颜色关系与调色约束，不是新增的全局色板；不可将一个 RGB 值覆盖不同材料，也不可把 sRGB 颜色直接当作线性反照率。

| 部位 | 保留的颜色关系 | 调整方式 |
| --- | --- | --- |
| MIT 石材与穹顶 | 暖白、米白、浅石灰石色 | 依据实景保留石缝、颗粒、色差和可见磨损；清除无依据的噪点与贴图伪影，保留真实表面层次 |
| 檐口、柱廊和基座 | 与主石材同属暖浅色，靠受光和深度区分 | 保留接缝与构件层次，避免给每道收边另涂深色 |
| 玻璃与窗洞 | 现有灰蓝、灰绿玻璃与更深的内部遮蔽 | 保留框体、玻璃后退和随视角变化的反射，不改成统一蓝色贴片 |
| 木门与金属 | 既有木棕、低饱和金属色 | 依据实景保留木纹、漆层、金属粗糙度、五金与磨损，不统一涂平 |
| 草坪与树木 | 绿色、黄绿色及自然树荫 | 以疏密、亮暗与小幅冷暖组织树冠；保留树干和天空间隙 |
| 铺装 | 现有暖灰和灰米色 | 保留真实分缝、颗粒、板块色差与可见磨损，路缘及台阶用几何和接触阴影读出 |
| 水域与天空 | 既有蓝绿色水面、自然蓝天和轻云 | 以反射与轻微波纹增加流动感，避免全场景蓝色滤镜 |

自然日光维持当前晴朗、偏暖的方向。阴影允许带少量天空冷色，但不得把石材亮面染成冷白、植被去色成白色，或把整个世界改成靛蓝夜景。

## 4. 造型与材质执行规则

### 4.1 建筑必须先站得住

- 按实景校准 Great Dome 的穹顶曲线、鼓座、主楼体块、柱列比例和相互位置；主立面、两翼与 Killian Court 的空间关系保持可追溯。
- 柱础、柱头、檐口、窗框、窗台、门洞、台阶和可接近的收边保留实际几何。光影与氛围组织不能替代构件建模，不把开口深度变成贴图。
- 近景依靠有依据的构件层次成立；只在有记录的远景分级中精简无法分辨的细小构件，保留完整源模型。各建筑的立面节奏与轮廓不能变成统一模板。
- 记录本轮实际修改类别。只调整旧模型材质和光照时，应称“材质精修 / 运行时表现”，不能称“完成主楼重建”。

### 4.2 现实材质细节优先

- 石材依据实景保留分缝尺度、颗粒、微表面凹凸、板块色差、磨损与风化，并使其与构件转折和接触关系一致；不因追求干净画风而整体压平。
- 保留石材、玻璃、金属、木材、草地的粗糙度与反射差异。不能只给所有对象设置同一平涂材质。
- 可见磨损与污渍按实景保留，不能以风格化为由笼统省略，也不能用无依据的随机噪点冒充真实细节。无需逐像素复刻每一处痕迹，但须保持相应的材质状态与尺度；窗洞侧壁、门框厚度、栏杆和台阶保留实际构造。
- Base Color 不烘入定向阳光、镜面高光或固定倒影。AO 用于接触关系，不把墙角描成粗黑线。
- 玻璃结合真实框体、后退深度、窗后遮蔽和环境反射判断；不能仅提高亮度或换成浅灰蓝色块来声称更真实。
- 材质源参数和尺度保持可追溯；先检查正常步行距离与近景的实景对照，再决定贴图分辨率。过滤远处混叠，不删除完整材质中的现实细节。

### 4.3 明暗有结构，空气感保持克制

- 建筑亮面、背光面与柱廊内侧形成清晰层次；亮面保留细节，阴影中能看见入口和构件。
- 光影组织不得压掉构件转折、细部遮蔽或材质微表面反应；曲面保留体积连续性，避免把穹顶切成阶梯色带或把柱头、梁底压成同一平面。
- 远景薄雾用于距离层次，不用于遮挡建模缺口；近处石材、树干、台阶和草坪边缘保持清楚。
- 泛光限制在确有明亮反射或高亮的小范围内。默认不增加重景深、强暗角或全屏漂白。
- 描边仅在确有助于结构识别时少量使用，不能用粗黑轮廓取代真实几何与接触阴影。

### 4.4 环境服务于真实校园

- Killian Court 的草坪、步道、路缘和树木位置保持既有实景依据。不得为了模仿视频将草坪变成水面。
- 植物保留实景中的自然树形、主次枝、叶片疏密、树冠层次与真实接地；过滤纹理混叠和阴影伪影，不将可见枝叶细节当作杂讯消除。
- 风动轻柔且方向一致；如加入漂浮叶片或微粒，应稀疏、局部、可降级，不能遮挡穹顶、窗列或行走路径。
- 水波与反射仅用于已有水域，保留河岸关系和可行走边界；MIT 主楼样板不以新增水景为前置条件。

## 6. 样板验收与交付

G0–G4 继续按 [开发规范](development-standards.md) 自检。当前文件设定制作方向，不记录任何关卡已通过。

1. **G0 参考与范围**：保存原版基线、实际参考照片及位置依据，明确模型来源和未知方向。demo 标为风格参考。
2. **G1 形体与接地**：中性材质核对穹顶、鼓座、主楼、柱廊、台阶与草庭关系，避免光影掩盖几何问题。
3. **G2 构件与材质**：在中性光和游戏光下对照实景检查窗洞进深、材料区分、石缝与微表面、磨损、玻璃深度反射、铺装分缝、色温和阴影层次。不能以表面简化替代现实细节还原。
4. **G3 实际游玩**：在 Pulsetact World 中加载实际资产，保存正面、左右斜视、柱廊与入口近景；走完草庭边缘至主楼的既有路线，检查碰撞、台阶、转身与接地。
5. **G4 分级与交付**：保存可编辑源或程序参数、导出 hash、实际运行截图、完整/低档差异和资源记录。记录设备与画质；浏览器模拟不等于移动真机验证。

前后对照尽量固定相机、FOV 与画质；光照改变必须写明。视觉结论分别回答：建筑结构是否有实景依据、当前风格是否成立、普通游玩视角是否稳定。通过构建或测试只能说明相应技术项，不能代替美术验收。若仍有形体、构件、运行或分级缺口，应交付为阶段样板并列出具体问题。
